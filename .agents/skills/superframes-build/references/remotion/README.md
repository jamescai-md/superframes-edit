# Remotion knowledge, vendored

The Remotion skill set as published by [remotion-dev/remotion](https://github.com/remotion-dev/remotion)
(`packages/skills/skills`), copied here so `superframes-build` carries the React track with no
second install and no network fetch. MIT-licensed; see `THIRD_PARTY_NOTICES.md` at the repo root.

Read them in this order:

| File | Use |
| --- | --- |
| `remotion-best-practices/SKILL.md` | the router: which sub-skill for which job |
| `remotion-create/SKILL.md` | scaffolding a project and opening Studio |
| `remotion-markup/SKILL.md` | components, sequencing, timing, effects, media |
| `remotion-markup/compositions.md` | registering compositions and stills |
| `remotion-render/SKILL.md` | exporting, transparent video, codec flags |
| `remotion-captions/SKILL.md` | transcribing and displaying captions |
| `remotion-multimedia/SKILL.md` | probing and trimming with Mediabunny |
| `remotion-interactivity/SKILL.md` | markup that stays editable in Studio |
| `remotion-maps/SKILL.md` | Mapbox, MapLibre, MapTiler, Cesium fly-throughs |
| `remotion-saas/SKILL.md` | `@remotion/player`, rendering services, frameworks |
| `remotion-studio/SKILL.md` | the preview loop |
| `remotion-license/SKILL.md` | when a company licence is required |
| `remotion-upgrade/SKILL.md` | version upgrades |

Topic files sit beside their skill, e.g. `remotion-markup/ffmpeg.md`, `remotion-markup/audio.md`,
`remotion-markup/transitions.md`, `remotion-markup/silence-detection.md`, `remotion-markup/voiceover.md`.

This copy is a snapshot. Upstream is authoritative for a version-specific question; check
`https://www.remotion.dev/docs` when behaviour and this corpus disagree, and note the divergence.
